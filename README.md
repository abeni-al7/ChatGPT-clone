# ChatGPT Clone

A front-end mock-up of a ChatGPT-style chat interface in plain HTML, CSS and JavaScript. It does not connect to any AI model or API: it only renders the chat UI.

## Features

- Prompt textarea with a send button
- Sent messages appear in the chat area as "outgoing" bubbles with a user avatar
- After each message a chatbot avatar with a three-dot typing animation appears
- Light-mode and delete icons are in the layout, but no JavaScript is attached to them yet

## Built with

- HTML, CSS and vanilla JavaScript (`index.html`, `style.css`, `script.js`)
- Google Material Symbols for the icons

## Run it

Open `index.html` in a browser. There are no dependencies to install.
